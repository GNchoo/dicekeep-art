# Simplified arena entrance and goal (v142)

The Infinity arena's entrance and destination were repainted with the Codex built-in image generator, without an API key. The previous runtime files are in `originals/`; the selected full-resolution transparent cutouts are `source-start.png` and `source-end.png`. `node tools/promote-arena-portals.mjs` trims excess transparency, fits each sprite inside its original 1024×1024 canvas with the foot at the bottom, and writes the two existing runtime paths. `promotion.json` records all source, original, and output hashes.

The entrance keeps the violet enemy portal but removes torches, little masonry blocks, and the wide ground slab. The goal keeps a cyan crystal as the dominant landmark, on a short cream pedestal. Both use the current wooden tower's clear outline and matte two-tone shading. They remain distinct when drawn at 84px (start) and 128px (end). There are no plants or theme-specific scenery.
