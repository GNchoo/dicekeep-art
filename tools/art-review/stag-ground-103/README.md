# 수사슴 부관 지상 이동 수정 · v103

W20 부관 `b020-2` 거대 수사슴은 원화·승인 리그·실제 manifest 모두 지상 사족보행이다. 세 방향마다 8포즈와 보폭 130이 이미 있지만, 이전 보스 선택기에서 물려받은 `eagleEmperor.move = air`가 게임 상태에 남았다. 이 때문에 걷는 그림 전체가 최대 42px 떠오르고 ±5px 흔들림과 공중 그림자가 적용됐다. 인피니티에는 단일 지상 레인만 있어, 이 문제로 경로가 단축되지는 않았다.

`INFINITY.bossMoveFor(w, role, baseMove)`는 101웨이브 로스터의 20번째 부관만 지상으로 분류한다. 큐의 레인 선택, 스폰 시 이동 판정, 관전 복원에서 같은 함수를 사용한다. W121의 `b121-2` 왕관 숲사슴과 이후 진화 반복에도 적용된다. 아트 다운로드·캐시·manifest 존재 여부에 의존하지 않으며 기존 보스 원형과 다른 캐릭터의 이동 분류는 유지한다.

기존 그림과 리그, 크기, 8프레임, 보폭은 재사용한다. 생성 요청 및 이미지 파일 변경은 0건이다. 체력·이동 속도·보상·방어력 수치는 유지한다. 지상 분류에 따라 조준점의 공중 높이 보정이 사라지고 기존 지상 보스의 발먼지·쿵음·짧은 흔들림이 적용되므로, 단순히 그림의 높이만 변경한 것은 아니다. 현재 모든 타워는 지상/공중 모두 공격한다.

게임의 `content.js`와 `game.js`만 `?v=103`으로 불러온다. 기존 아트 URL과 v102 보스 발끝 수정은 유지한다.

## 검증과 재현

```powershell
node --test tools/stag-movement-test.cjs net/test/infinity-art.test.js
npm run build:www
```

- 27개 테스트 통과: 아트·캐시·프로토콜 기존 25건과 이동 분류 회귀 2건.
- 아트 manifest가 있는 경우와 없는 경우에 각각 100로스터 주기 × 10보스 웨이브 × 2역할을 검사한다. 20번째 부관만 ground이며 기존 `eagleEmperor` 원형은 air와 원래 수치를 유지한다.
- 웹 패키지 복사 빌드 성공. 이번 수정에서 Android 실기기 플레이·APK 배포는 수행하지 않는다.
- 운영 원본 비교: W20/121/222 부관의 4방향과 관전을 확인했다. W20은 피벗이 지면보다 약 37.10–47.00 게임px 높았다.
- 로컬 수정본 `--smoke`: W20 하향 8프레임과 관전에서 지면 피벗 간격 최대 0.00001514px, W121/222 스폰은 front fallback 단계에도 ground/공중 높이 0이다. W4 비행 몬스터는 약 38.15–46.99px 비행 높이를 유지했다. 비교 가능한 스폰 수치 20개, 아트 응답 32개, 두 manifest SHA는 원본과 일치한다.
- 새 오류 0건이며 기존 선택형 BGM 404는 별도 기록한다. 원본/수정본 검사의 범위는 다르다. 수정본에서 12방향 전체를 다시 검증했다고 주장하지 않는다.
- 검사는 HTTP 게임 코드에 기존 내부 함수의 접근용 export만 추가해 큐·스폰·관전 함수를 호출한다. 웨이브와 위치를 고정하며 아트와 게임 함수 본문은 교체하지 않는다. 관전은 실제 직렬화/복원을 호출하지만 외부 멀티플레이 방에 접속하지 않는다. 피벗 검사는 텍스처의 모든 발굽 해부학적 접지를 보증하지 않는다.
