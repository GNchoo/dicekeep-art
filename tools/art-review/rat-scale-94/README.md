# 1웨이브 쥐 크기 조정

쥐와 해골은 같은 전투 크기 등급을 사용했지만, 낮고 긴 쥐의 몸을 인간형과 같은 높이로 표시하면서 쥐가 지나치게 크게 보였다. `w001`만 표시 높이를42→21(가로·세로50%, 면적25%)로 조정했다. W2해골은42를 유지한다. 전투 크기·이동 속도·체력·공격 판정과 원본 PNG는 그대로다.

로컬 스폰과 관전은 같은 표시 높이 함수를 사용한다. W102처럼 반복 주기의 쥐도21, 정예 쥐는 기존1.2배를 유지한25.2다. 사망 잔상과 걷기 보폭도 이 높이를 공유하므로, 작은 그림에 기존의 큰 보폭이 남지 않는다. `game.js?v=94`로 브라우저가 수정 코드를 받게 했다.

실제 휴대폰440×956 화면의8프레임 평균 측정에서 쥐 옆모습은56.15×25.13px→28.07×12.57px다. 해골은12.89×25.44px로 유지됐다. 불투명 전경 면적 비율은 쥐/해골4.71배→1.18배이며, 꼬리를 포함한 쥐의 낮고 긴 실루엣을 유지한다.

[수정 후 실제 검사](after/report.json)는 두 캐릭터의 네 방향에서 각각8포즈, PNG 요청, 실제 이동, 기절 시 위상 보존, 정예와W102를 확인했다. 추가로[기존 런타임 계약 검사](runtime-contracts.json)에서101웨이브 전투 수치, 관전, 부관 비율, 동일 캐릭터 대체 이미지와 타워 논리 탄도를 확인했다. 수정 전 기록은 완료된 네 방향 크기 측정만 사용하며, 이후 정예 스폰용 검사 설정의 timeout을 전체 통과로 집계하지 않았다.
