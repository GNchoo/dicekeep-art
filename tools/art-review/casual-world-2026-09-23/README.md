# 캐주얼 타워·월드 리페인트 (v123)

사용자가 승인한 1성 목조 망루를 화풍 기준으로 삼아, 원본의 형태를 보존하는 방향으로 제작했다.

- 2~6성 기본 타워 5종: 쌍포, 마법석, 얼음, 전기 코일, 왕관·깃발 구조 유지.
- 투사체 5종, 포구 섬광 1종, 명중 2×2 시트 4종.
- 사용 중인 투기장 타일 9종, 초원 타일 12종, 공용 포탈·크리스탈 2종.
- 총 38개 생성 원본, 43개 런타임 경로. 별도 API 키 없이 **Codex 내장 image_gen**으로 자산마다 독립 호출.

정확한 초기 프롬프트와 참조 경로는 [`tools/casual-world-jobs.json`](../../casual-world-jobs.json), 도로의 가장자리 페이드 수정 프롬프트는 `road-revision.json`에 보관했다. 원본은 `originals/`에, 선택한 생성 결과는 이 디렉터리에 보관한다. 참조 파일의 제작 당시 내용은 `9a69b7a`와 `originals/`에서 확인할 수 있다. 모델 스냅샷은 내장 도구가 공개하지 않으므로 임의로 기재하지 않는다.

## 런타임 연결

`node tools/promote-casual-world.mjs`는 저장된 결과를 리사이즈·인코딩하고 `promotion.json`에 원본/소스/결과 SHA-256을 기록한다. 타워는 기존 파일의 외곽 크기 안에 비율을 유지하여 배치하며, 게임의 70×96px 최대 크기와 바닥 피벗을 유지한다. 배치 전 미리보기도 실제 장착 스킨을 사용한다.

타워별 포구/마법석/코일의 좌표는 `combat-motion.js`에서 관리한다. 타워 1의 승인된 붉은 렌즈 공격은 유지한다. 2~6성의 시각적 발사 위치만 연결하며 피해량·연사·투사체 물리 좌표·명중 시간은 바꾸지 않는다. 새 RGBA 자산은 기존 회색/마젠타 배경 제거를 건너뛰어 밝은 외곽과 반투명 이펙트를 보존한다.

개별 타일팩이 없는 숲·호수·어두운 숲·성·용암 지역은 새 공용 타일을 맵 생성 시 한 번 색상 조정하여 사용한다. 전용 지역 자산이 있으면 우선하고, 공용 타일 캐시는 현재 지역만 유지한다. 별도 다운로드나 프레임별 필터는 없다.

별도 구매 스킨과 7~20성 아트, 몬스터/보스, 폐기된 통짜 배경은 이번 2~6성·환경 작업의 교체 대상에 포함하지 않았다.

## 확인

`npm run test:casual-world`, `npm run test:combat-motion`, `npm run test:art-pipeline`, `npm run build:www`.
미리보기는 `node tools/build-casual-world-review.mjs`로 생성하며, `docs/casual-world-v123.html`에서 타워 전후·공격 효과·투기장·6개 지역을 확인한다.
