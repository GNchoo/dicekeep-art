# PR #29 · 이전 시트 처리 기록

이 폴더의 4프레임 지상 보행 판정은 사용자 GIF 검토에서 발견된 양발 교대 누락으로 철회했다. 중심점·발 높이 안정화 통과는 올바른 걷기의 증거가 아니었다.

현재 적용된 지상 7종의 8프레임 보행, 다리별 접지 검사, 최신 GIF와 게임 검증은 [새 보고서](../pr29-gait/README.md)를 따른다. 이 폴더의 evidence는 이전 결과이며 현재 지상 보행의 증거로 사용하지 않는다.

기존 원본과 프롬프트는 제작 이력으로 보존한다. W4 까마귀·W8 파리·W10 정지 보스의 승인된 아트는 이 원본에서 계속 재생성한다. `rebuild.mjs`는 현재 최종 PNG 19개를 만드는 새 스크립트로 연결된다.
