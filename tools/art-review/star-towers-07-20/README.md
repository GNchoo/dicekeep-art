# 7–20성 전용 타워 원화

7–20성의 실제 건축 원화 14종을 네 테마 atlas로 제작하고, `casual/towers/star-07.png`부터 `star-20.png`까지 투명 384×384 PNG로 분할했다. 기존 6성 타워의 색상 변경판이 아니다.

- 별빛 7–10: 쌍결정첨탑, 프리즘포대, 천체관측탑, 별왕관천문성.
- 성운 11–14: 차원문요새, 공중성채, 중력핵요새, 쌍성성채.
- 천공 15–18: 날개신전, 천공전투성, 태양대성당, 다층천상옥좌.
- 차원 19–20: 균열관문, 우주핵군주성.

실제 builtin `image_gen` 호출은 **5회**다. 4+4+4+2종을 묶은 최종 atlas 4장과, 폭이 넓어 교체한 최초 별빛 atlas 1장을 모두 보관한다. 도구는 금액/토큰 비용을 제공하지 않았다. `prompts.json`에 실제 요청 전문, `call-ledger.json`에 호출 순서·선택 상태·원래 생성 경로·보관 원본 SHA256이 있다. CLI 이미지 생성과 대체 원화는 사용하지 않았다.

요청과 달리 실제 생성물은 알파가 없는 RGB 체크무늬 이미지였다. 선택 원본 3장은 1254², 차원 2종 원본은 1774×887이다. `extraction.json`의 실제 gutter 좌표로 분할하고, 바깥에 연결된 중립 흰색/회색 배경만 flood-fill했다. 닫힌 관문·공중성채 줄 사이·고리·성당 지지대 빈 공간은 직접 확인한 **17개 원본 좌표 seed**로 제거한다. 좌표는 원본 SHA256으로 잠겨 있으며 바뀐 원본에 자동 적용되지 않는다. 흰색 석재의 내부 하이라이트와 마젠타 마법 효과는 색만으로 제거하지 않는다.

최종 PNG의 발 기준은 y376, 전신 높이는 360px이며 투명 여백이 있다. 실제 게임의 foreground crop 후 비율 유지 70×96 fit에서 14종 모두 높이 96px, 폭 70px 이하가 된다. `evidence/towers-actual-size.png`는 이 크기를 그대로 재현한 검수판이며, `towers-4x.png`와 `towers-alpha-light.png`는 확대·밝은 배경 검수판이다. 이는 캔버스 게임 실행 화면과 구분되는 정적 원화 검수다.

각 타워의 주사위 명판은 모두 **표준 D6의 5눈(네 모서리+가운데)**이다. 성 수를 7개 이상의 눈으로 표현하지 않는다. 70×96에서는 작은 명판의 개별 눈보다 건물 외곽·주무기·테마 색이 먼저 읽힌다. 넓은 공중성채·관문·왕관이 주변 셀로 넘치지 않도록 세로형 실루엣을 사용했다.

생성기가 요청한 고정 포구 좌표를 완전히 지키지는 않았다. 시각 포구와 기존 논리 발사점 사이 차이는 최대 약 17.7px다. 9성은 오른쪽으로 돌출한 망원경 렌즈, 16성은 약간 왼쪽을 향한 포대의 중심을 사용한다. `emitter-metadata.json`과 `manifest.json`은 실제 foreground bbox 기준 정규화 포구 좌표를 제공한다. 프로덕션 연결 담당은 이 좌표로 발사 섬광과 탄환의 초기 시각 오프셋을 맞추고, 논리 탄환의 위치·피해·도달시간은 유지한다. `towers-firepoint-review.png`의 노란 원은 원화 포구, 분홍 십자는 기존 고정 발사점이다.

저장소 루트에서 재현 및 검증:

```sh
node tools/art-review/star-towers-07-20/rebuild.mjs
node tools/art-review/star-towers-07-20/validate.mjs --rebuild-check
node tools/art-review/star-towers-07-20/browser-check.cjs
```

검수 결과는 `evidence/validation.json`에 기록한다. 14종 크기·알파·투명 테두리·발 기준·렌더 크기·포구 좌표 범위·파일 SHA256·재빌드 동일성을 확인한다. 자동 검사는 실제 게임 연결이나 미적 평가를 대신하지 않는다. 원본, 최종 PNG, 프롬프트, 분할 좌표, 해시와 검수판을 함께 보관한다.

실제 게임 검증도 완료했다. 데스크톱 1440×1080 및 휴대전화 440×956 각각에서 14 PNG 요청 성공, 14개 고유 스프라이트 실제 `drawImage` 관찰, 실제 `towerFire` 발사 14종을 확인했다. 합계 **실제 렌더 28/28, 발사 검사 28/28**이며 `evidence/browser-validation.json`에 세부 수치가 있다. 포구 섬광과 발사 직후 표시점이 일치하고, 논리 발사 위치는 기존 `(t.x,t.y-64)`를 유지하며 0.1초 시각 오프셋이 0으로 수렴한다. 전체 도달시간이나 피해 밸런스의 포괄적 회귀검사는 이 검수의 범위가 아니다.

`browser-check.cjs`는 테스트 페이지에서만 현재 저장소 `game.js`의 기존 디버그 훅 위치에 함수 참조를 추가해 관찰한다. 프로덕션 함수 본문은 바꾸지 않으며 원본 게임 파일 SHA를 기록한다. 실행 서버는 기본 `http://localhost:8137/`, 변경 시 `E2E_BASE_URL`을 사용한다. `evidence/runtime-*.jpg`는 실제 게임 캡처이며 저장 크기는 폭 1240px 이하, JPEG 품질 85다. 조밀하게 배치한 데스크톱 화면에서는 기존 성 표시 배지가 뒷줄 건물 일부와 겹친다. 전용 원화의 오염·잘림은 없었고 휴대전화에서도 테마/실루엣이 구분된다. 배치 UI 간격은 이 아트 작업에서 변경하지 않았다.
