# v165 — 덱 조합 안내와 비교

## 참고 조사
- [Apple의 랜덤 다이스 2 소개](https://apps.apple.com/kr/iphone/story/id6793009149)는 다섯 속성, 독·둔화·보스 대응 역할, 일반 몬스터와 보스에 대응하는 균형, 자원을 쓰는 확정 연구 경로를 안내한다.
- [111%의 공식 App Store 설명](https://apps.apple.com/kr/app/id6748432502)은 선택 가능한 성장 경로, 7성 각성, 서포터를 강조한다.
- 위 공개 자료에서 단일 전투력 점수나 상세한 실시간 덱 비교 화면은 확인하지 못했다. 이번 수치 비교는 우리 게임 규칙으로 만든 개선이며 랜덤다이스2에 같은 기능이 있다는 뜻은 아니다. 계열 이름만 보여주기보다 역할 → 효과 → 배치 → 연구 전후 순서로 판단하도록 구성했다.

## 적용
- 내 덱과 추천 덱: 일반/보스 초당 직접 피해, 현재 선택한 저장 덱 대비 증감, 인접 배치 효과.
- 추천 덱: 역할 카드, 배치 예시, 발동 조건. 좁은 화면은 배치·시너지 상세 페이지로 이동한다.
- 연구: 카드에 효과를 바로 표시하고, 연구 전후 수치와 함께 쓰는 주사위를 확인한다. 별도 성능·연계 페이지는 작은 화면에서도 접근 가능하다.
- 공통 메뉴 크기를 유지하면서 큰 빈 영역을 수치·배치 예시로 채웠다. 스크롤은 사용하지 않는다.

## 수치의 뜻과 한계
`DKDECKRULES.stats`를 재사용한다. 종류별 3눈금 1기, 파워업 1단계, 현재 계정 연구, 직접 피해가 높은 타워를 중심에 놓는 고정 십자 배치다. 최적 배치나 승률 예측이 아니다.
일반 직접 피해는 피해/공격 주기의 합이다. 보스에는 추적의 보스 배율만 추가한다. 인접 효과는 같은 다섯 타워를 각각 단독 배치한 경우 대비 증감이다. 고독처럼 이웃 때문에 약해지는 경우 음수가 될 수 있다.
광역, 독, 둔화 연계 추가 피해, 주기 폭발, 치명타, 방어력, 사거리 안 체류시간은 합산하지 않는다. 경제·성장·운영 효과도 점수로 환산하지 않는다. 해당 능력과 조건은 상세 화면에 표시한다. 7눈금 각성은 3눈금 수치를 부풀리지 않는다.
이 비교는 덱빌드·극한·협동 연구 기준이다. 순수운빨은 해당 덱/연구를 사용하지 않으며 대전의 성장 수치는 통일된다.
