# 모드 개발 진행

## 현재: 모드 밸런싱과 무료 성장 (2026-09-14, v116)

협동 목표를 500→700 공동 처치로 늘렸다. HP 20, 90초 보스, 일반/보스 이탈 피해 1/5와 무료 아군 보급을 유지하며, 전투 규칙을 `battle-rules.js`에서 브라우저와 서버가 공유한다. 대전은 보유한 덱 선택을 유지하되 숙련 0·특성/각성 미적용·기본 클래스/레벨로 수치를 통일한다. 연구 투자와 유료 조각은 협동·덱빌드·극한의 성장에 쓰이고 대전의 공격력 차이를 만들지 않는다. 후보·대전·최종 설정 총 18쌍의 실제 자동 전투를 비교했고, 신규 기본 무료 덱은 최종 두 시드에서 454초에 HP 8·10으로 완주했다. 중간·최대 성장도 통과했으며 혼합 경제 조합 한 판은 684/700처치에서 실패했다. 비교 시험과 자동 운영의 한계는 [전투 밸런스](BATTLE-BALANCE.md)에 기록한다.

대전·협동은 유효 참여 1분당 연구 골드 300 + 조각 8, 60초 이상 참여한 승리에 100골드 + 5조각, 모드별 첫 승리에 추가 300골드 + 20조각을 지급한다. 패배도 같은 시간 기본 보상을 받는다. 10/30/60/120/240/480분 누적 보너스는 기한 없이 한 번씩 지급한다. 개인 처치 비중을 보상에 적용하지 않는다. 자세한 비용·성장 일정·가정은 [무료 성장 설계](FREE-PROGRESSION.md)를 본다.

계정 정산은 외부 Durable Object 바인딩으로 방의 좌석과 종료 영수증을 확인한다. 서버가 타워 3개 이상·접속·화면 표시가 연속 관찰된 시간만 누적하고, 방 종료 뒤에도 보상 영수증을 30일 보관한다. 같은 경기·좌석의 중복 계정 청구와 같은 계정의 양쪽 좌석 청구를 막는다. 게스트도 같은 계산식을 쓰며, 저장 실패 시 체크포인트를 보존해 재시도한다. 이 검증은 결과·시간·소유권·중복 지급 검증이며 전투 시뮬레이션 전체의 서버 검증을 뜻하지 않는다.

상점은 무료와 동일한 200/600조각 소액 상품과 외형으로 정리했다. 전체 연구 비용 1,440조각보다 큰 2,000조각 상품은 새 판매 목록에서 제외하고 이전 영수증 호환은 유지한다. 구매·입장권·연속 출석·기한 이벤트 없이 모든 종류와 연구를 마칠 수 있다. 기존 웨이브 보상과 연구 비용, 순수운빨·아트·★ 종류 숫자와 전투 눈금은 유지했다.

확인: 진행·무료 보상·저장 49개, 네트워크 서버 136개, 상거래 53개, 상거래 클라이언트 13개, 순수운빨 84개, 모드 통합 106개, 기존 저장 복원 60개. 계정 요청 지연 중 종료·이탈과 구 시범전 호환 10개도 통과했다. 실제 두 브라우저 9개 경로에서 재접속·ACK 중복·보스·승패·유효 참여·0처치 지원 보상·게스트 저장 실패 복구를 확인했다. 실제 workerd 두 Worker와 SQLite에서 외부 DO 바인딩, 62초 참여 정산, 동시 요청, 객체 eviction 후 영수증 재조회를 검증했다. 모든 결제 검사는 가짜 공급자 또는 비활성 상태로 수행했다. 운영 로그인·결제 URL이 미구성인 상태의 실제 계정 서비스 배포를 의미하지 않는다.

## 별 숫자 복구 (2026-09-14, v114)

사용자의 정정에 따라 타워 머리 위의 기존 `★20` 형식(종류 번호)을 복구했다. v113에서 추가한 주사위 점 아이콘은 제거하고 전투 눈금은 발밑의 숫자 1~7로 표시한다. 머리 위에 `각성` 같은 추가 문구를 붙이지 않으며 각성 아우라는 유지한다. 전투 수치와 연구·저장 규칙은 변경하지 않았다.

## 각성 아우라와 눈금 표시 (2026-09-14, v113)

휴대폰에서 읽기 어려운 머리 위 `7눈금 · 각성` 텍스트를 금빛 바닥 아우라·회전하는 빛·상승 입자로 대체했다. 1~7눈금은 어두운 받침의 주사위 점으로 표시하며, 기존 덱 타워 밑에 잘못 남아 있던 3단계 레벨 점도 함께 교체했다. 타워 선택창의 상세 설명과 기존 전투 수치는 유지한다. 원래 순수운빨·캠페인의 별/레벨 표시는 그대로다. 관전 상대의 각성은 내 연구 상태로 추정하지 않는다.

휴대폰 390×844와 PC 1240×860에서 15기 배치·1~7눈금·각성/비각성·시간에 따른 아우라를 확인했다. 큰 화면의 눈금 아이콘 폭은 30px로 제한한다. 실제 3브라우저 멀티 10개 항목(관전 아우라 오인 방지·내 각성 유지·재접속·정산)과 정적 앱 빌드가 통과했다.

## 다이스 트리·7눈금 각성·서포터 (2026-09-14, v112)

랜덤다이스 2의 다이스 트리와 각성·서포터 구조를 Dicekeep의 20종에 적용했다. 자연·마법·공학·질서·혼돈을 따라 원하는 종류를 확정 해금하고, 숙련 0~5·두 특성 중 선택·7눈금 고유 각성을 연구한다. 보급관·분쇄관·포격관은 처음부터 무료 선택이며 전투 버튼으로 사용한다. 카드 그림은 숫자 눈금 대신 종류별 타워로 바꿔 종류와 눈금을 구분한다.

무작위 카드 보급과 중복 제작을 확정 연구로 교체했다. 신규 기본 여섯 종류와 1,860 연구 골드를 제공하며, 기존 클래스 투자·중복·보급은 숙련과 연구 골드로 한 번 환산하고 초과액도 보존한다. 특성 변경·서포터 변경은 무료다. 기존 외형 + 동일 자원 소액 상품의 가격을 유지하고 상점 설명을 새 연구 비용에 맞췄다. 자세한 규칙·비용·참조 출처는 [DICE-TREE.md](DICE-TREE.md), 과금은 [BUSINESS-MODEL.md](BUSINESS-MODEL.md)에 있다.

새 규칙은 시작 스냅샷의 `treeVersion:1`에만 적용한다. 기존 레벨 런·v111 클래스 런은 당시 상태로 복구하며, 순수운빨과 캠페인의 전투 규칙은 유지한다. 몬스터·타워 몸체·무릎 아트는 변경하지 않았다. 온라인 방은 v112끼리 입장하며 진행 중인 v111 온라인 방의 버전 변경 제한은 다이스 트리 문서에 명시했다.

확인한 검사: 트리 UI 206, 진행 33, 상거래 서버 46, 클라이언트 12, 구매 확인 두 화면, 멀티 서버 120. 새 트리 저장·복구 24개와 이전 두 세대 × 휴대폰·데스크톱 4경로를 통과했다. 순수운빨은 최대 숙련·각성 계정과 신규 계정을 비교한 84개 검사와 원본 101웨이브 전체 규칙 fixture가 일치했다. 새 전투와 모드 통합에서는 타워 정보창이 서포터를 덮는 문제와 데스크톱 버튼 밀림을 찾아 수정하고 실제 클릭 가능 여부를 검사했다. Android 정적 패키지 빌드에 tree-rules를 포함했다. 실결제나 실제 휴대폰 하드웨어 성능 검증은 포함하지 않는다.

최종 전투 80개·모드 통합 106개와 기존 v111 전투 150개를 통과했다. 실제 세 브라우저의 극한 멀티 검사 10경로에서 종류·눈금 관전, 휴대폰 재접속 및 새 네이티브 저장 컨텍스트의 숙련·특성·각성·서포터 잔여 시간 복구, 순위와 정산 중복 방지를 확인했다. 상대 보드에 내 각성 연구가 표시되지 않으며 관전 중 내 각성 생산 능력은 유지됨을 실제 그리기 경로와 전투로 검사했다. 만료된 각성 중독·방어 약화가 다음 일반 공격에 남지 않는 회귀 검사도 포함했다.

무료 전투 표본: 기본 덱 속사·포격·비전·서리·뇌전, 숙련 0·특성/각성 없음, 보급관, 고정 시드 41073으로 실제 브라우저의 101웨이브를 완주했다. 추가 SP 주입 없이 전투에서 번 자원과 실제 재사용 시간을 적용한 보급 36회로 진행했다. 시뮬레이션 전투 시간 34분 35초, 소환 131회·합성 129회·마지막 총 눈금 48, 배치 불가로 멈춘 횟수 0이었다. 자동 배치 한 표본으로 사람의 승률이나 전체 조합 균형을 뜻하지 않는다. `npm run measure:deck -- --case=fresh`로 재현하며 결과는 `gen/e2e/deck-balance/extra-report.json`에 남는다.

## 이전: 수집·덱 전투 개편 (2026-09-14, v111)

1~20성 해금과 계정 레벨 중심 편성을 20종 능력 카드·5종 덱·3개 프리셋·클래스 성장으로 교체했다. 새 덱빌드와 극한은 1~7눈금 합성, 모사/새싹, 종류별 SP 강화, 인접 지원과 상태 연계를 사용한다. 아래 v105 이전의 레벨·성장 수치와 측정은 역사 기록이며 새 덱 전투의 현재 밸런스가 아니다.

기존 투자는 한 번 환산하며 구버전 진행 중 전투는 기존 스냅샷으로 복구한다. 무료 카드 보급과 원하는 카드 확정 제작을 제공하고, 상점의 외형 + 소액 조각 상품은 유지한다. 상세 규칙·이전·초기 전투 표본은 [DECK-SYSTEM.md](DECK-SYSTEM.md), 과금은 [BUSINESS-MODEL.md](BUSINESS-MODEL.md)에 기록했다.

수집 UI와 새 전투는 휴대폰·데스크톱에서 검증한다. 순수운빨의 원본 데이터·12웨이브 전투 fixture, 구/신규 이어하기, 모드별 정산, 계정 원장·결제 회귀, 새 눈금 관전 패킷도 함께 확인한다. 아트·몬스터 무릎·기존 타워 몸체 모션은 이번 변경 대상이 아니다.

완료 검사: 수집 UI 82, 새 전투 150, 모드 통합 104, 순수운빨 84; 구/신규 이어하기 × 두 화면 4경로; 진행 모듈 24, 상거래 서버 43, 클라이언트 12, 멀티 서버 120. 실제 세 브라우저의 새 눈금 관전·폰 재접속·앱 재시작 모사도 통과했다. `build:www`에 새 모듈 두 개가 포함됨을 확인했다. 자동 전투 6개 조합 중 신규 기본 덱을 포함한 4개 조합이 시작 클래스로 101웨이브를 완주했다.

## 덱빌드와 공통 성장 (main `72be7e1`)

- main의 순수운빨 12웨이브 전투/소환 결과를 3개 시드·2개 화면의 고정 fixture로 보관했다. `npm run test:pure-main`으로 재현한다.
- 모드별 웨이브 선택 경계를 만들었다. 순수운빨 수치와 덱빌드 체력은 유지했다. 아직 근거 없이 체력을 다시 조정하지 않았다.
- 성장 모드 확률강화가 기존 성장 배율을 이어받는다. 큰 배율 하나만 적용해 반복 곱셈을 막는다. 성장 모드는 모든 별의 타워를 판매할 수 있다.
- 덱 화면에 역할·계정 레벨·덱빌드/극한 적용 레벨과 배율을 표시했다. 선택한 1성 소환에 꽝 문구를 사용하지 않는다.
- Lv20 이후 성장 비용을 완화하고 기존 투자 차액을 한 번 반환한다. 외형 + 소액 성장 상품과 구매 확인 화면은 `BUSINESS-MODEL.md`에 기록했다.

## 보스 이동 오류 수정 (2026-09-14, v106)

100웨이브 파멸의 군주는 기존 태엽올빼미의 공중 속성을, 공허 용은 생쥐마왕의 지상 속성을 잘못 물려받고 있었다. 회전하는 능력치 원본과 보스의 이동 분류를 분리했다. 80웨이브 화룡/히드라와 극한의 같은 유형도 수정했다. 보행 보스는 지상, 날갯짓 보스는 공중이며 떠다니는 마법사 계열의 기존 이동은 유지한다. 이 규칙은 아트 로딩 성공 여부와 무관하다.

기존 v105 이어하기의 적과 투사체 표적에도 보정한다. HP·거리·진행 기록·계정 티켓을 보존한다. 멀티 관전도 같은 이동 규칙을 사용한다. 이동 분류가 바뀌면 표시 높이와 타워의 공중 판정/조준 위치는 함께 바뀐다. 체력·속도·보상·뽑기 확률의 수치 조정은 없다.

`npm run test:boss-locomotion`은 실제 게임으로 8주기의 모든 보스, 휴대폰/데스크톱, 관전, 구버전 저장 복구, 아트 누락을 검증한다.

## 인간형 무릎 방향 수정 (2026-09-14, v110)

최종 103종(기존 51·극한 52)의 무릎 방향을 수정하고 승격했다. 98종은 세 방향 모두, w002·w003·w005·w007·w009 다섯 종은 정면/후면만 수정해 정상 측면을 유지했다. 처음 측면만 살핀 감사가 놓친 방향 차이도 함께 수정했다. 카탈로그에서는 `biped`로 묶였지만 실제 그림이 닭 형태인 w075·w176은 의도된 hock의 뒤쪽 굽힘을 유지한다.

기존 부위 원화를 사용해 304수정뷰의 보행 2,432프레임, 정지컷/시트 608파일 및 fallback 304개를 재생성했다. 무릎 방향만 앞으로 바꾸며 기존 v102 정면 발끝 반전·소켓·링크 길이·접지·보폭·위상·피벗·크기를 보존했다. 몸통 변형이나 타워 변경은 추가하지 않았다. 수정 방향의 캐시 버전은 110이고 `anatomy: biped`에 전방 무릎 검사를 적용했다.

전체 빌드·관절·래스터 무결성·이동 검사와 최종 `npm run test:biped-knees`가 통과했다. 단위/관절 26건과 세 방향 감사, 실제 103종×3방향×2화면의 배치 618건, 서버 이미지 608개·fallback 304개 디코드를 확인했다. 비대상 118종 전체 및 초기 다섯 종의 측면 메타데이터·718이미지는 `5630cdd`와 동일하고 페이지/아트 오류는 0이었다. 일반 몬스터의 기존 땅속 이동과 W100 보스의 지상/비행 분류도 보존했다.
