## 보스 이동 오류 수정 (2026-09-14, v106)

100웨이브 파멸의 군주는 기존 태엽올빼미의 공중 속성을, 공허 용은 생쥐마왕의 지상 속성을 잘못 물려받고 있었다. 회전하는 능력치 원본과 보스의 이동 분류를 분리했다. 80웨이브 화룡/히드라와 극한의 같은 유형도 수정했다. 보행 보스는 지상, 날갯짓 보스는 공중이며 떠다니는 마법사 계열의 기존 이동은 유지한다. 이 규칙은 아트 로딩 성공 여부와 무관하다.

기존 v105 이어하기의 적과 투사체 표적에도 보정한다. HP·거리·진행 기록·계정 티켓을 보존한다. 멀티 관전도 같은 이동 규칙을 사용한다. 이동 분류가 바뀌면 표시 높이와 타워의 공중 판정/조준 위치는 함께 바뀐다. 체력·속도·보상·뽑기 확률의 수치 조정은 없다.

`npm run test:boss-locomotion`은 실제 게임으로 8주기의 모든 보스, 휴대폰/데스크톱, 관전, 구버전 저장 복구, 아트 누락을 검증한다. 자연스러운 전신 모션의 아트 교체는 이 오류 수정과 별개이며, 조사 내용과 제작 순서는 `MOTION-UPGRADE.md`에 기록했다.

이 수정의 검증 결과: 두 화면 합계 318회 보스 생성, 순수운빨 기준 84개 검사, 비행/부유 위상 54개와 5개 보스 구간·아트 재로딩 검사, www 빌드가 통과했다. 기존 방향별 회귀 도구가 신규 극한 아트 출시 전의 b010 부관을 기대하던 부분은 이전 커밋에서도 실패함을 재현한 뒤, 현재 b111-2와 실제 전송 외형 코드에 맞췄다.
