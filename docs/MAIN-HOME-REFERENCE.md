# 메인 화면 UX 참고와 적용 기준

조사일: 2026-09-14. 이번 작업은 랜덤 다이스 계열의 덱 준비·전투·성장을 구분하는 흐름을 참고해 Dicekeep의 메인 화면을 만드는 작업이다. 원작 이미지, 로고, 아이콘, 문구, 화면 좌표를 복제하지 않는다. 기존 성채 키아트와 타워 자산을 사용한다.

## 공식 화면에서 직접 확인한 범위

Google Play 개발자 등록 스크린샷을 브라우저의 확대 보기로 열어 관찰했다. 스토어의 홍보 이미지는 실제 게임 화면 일부를 확대하거나 문구로 가린 이미지이므로, 잘린 부분을 추측해 최신 홈의 전체 배치라고 설명하지 않는다.

RD2 스토어가 연결한 [111% 공식 트레일러](https://www.youtube.com/watch?v=AlN7PBGYr8A)도 브라우저로 열었다. 인증된 111% 채널이며 전투 장면을 확인했다. 이 영상과 위 스크린샷만으로 현재 홈의 모든 상단 재화, 하단 탭 순서, 출석 팝업의 재노출 조건, 빨간 점의 판정 규칙을 확인했다고 주장하지 않는다.

## Dicekeep v118에 적용한 다섯 가지

아래는 공식 자료에서 읽은 흐름과 사용자의 요구를 바탕으로 정한 Dicekeep 자체 설계다.

1. **접속 직후 보상 확인:** 부팅·계정 조회·멀티 복귀 확인이 끝난 타이틀에서 오늘 출석을 아직 받지 않았다면 바로 출석 창을 연다. 시작 버튼을 먼저 누를 필요가 없다. 이미 수령했거나 전투·방 복귀 중이면 열지 않는다. 같은 접속에서는 계정과 한국 날짜마다 한 번 자동 표시하며, 닫은 뒤 메뉴를 왕복해도 반복하지 않는다. 미수령 상태에서 새로고침하면 새 접속에서 다시 표시한다. 날짜가 바뀌면 다음 안전한 타이틀/메인에서 새 출석을 안내한다. 수령 버튼은 자동으로 누르지 않는다.
2. **상단은 현재 상태:** 프로필/계정과 연구 골드·성장 조각·젬을 표시하고, 출석·우편·성장 패스는 각각 바로가기로 구분한다. 금액이 갱신되면 메인과 보상 창이 같은 값을 표시한다. 실 계정 재화와 게스트 재화를 섞지 않는다.
3. **중앙은 전투 준비:** 기존 성채 이미지, 도전 기록, 실제 선택 덱의 다섯 타워와 숙련, 싱글·멀티 진입 버튼을 표시한다. 타워를 누르면 덱 편성으로 이동한다. 순수운빨·덱빌드·극한·스테이지·멀티의 기존 진입 기능과 전투 규칙을 보존한다.
4. **반복 방문은 고정 탐색:** 홈·다이스·전투·상점을 하단의 짧은 이름과 아이콘으로 구분한다. 실제 구현된 목적지만 노출하고 미구현 순위·길드 등에 빈 버튼을 만들지 않는다. 전화기 화면에서도 버튼과 숫자를 읽을 수 있게 한다.
5. **빨간 점은 받을 보상만:** 우편은 유효하고 미수령인 보상 우편, 성장 패스는 XP를 달성한 미수령 무료 보상 또는 구매한 유료 트랙의 미수령 보상이 있을 때만 점을 켠다. 읽었어도 아직 받을 수 있으면 유지하고, 마지막 보상을 받으면 즉시 끈다. 구매하지 않은 유료 단계나 오류 상태를 수령 가능 알림으로 표시하지 않는다. 홈 바로가기와 보상 창 내부 탭이 같은 판정 결과를 쓴다.

## 동작 검증 기준

- 신규 게스트 접속: 출석 자동 표시 → 수령 → 보유량·출석 상태·패스 XP 동시 갱신.
- 수령 완료 후 새 접속: 같은 KST 날짜의 출석 창은 자동으로 다시 뜨지 않음.
- 팝업 닫기·메뉴 왕복: 수령 강제나 반복 팝업 없음. 보상 바로가기로 다시 열 수 있음.
- 미수령 상태의 새로고침: 새로운 접속에서는 타이틀에서 다시 출석을 안내함.
- 전투·방 복귀: 복귀 확인을 먼저 마치며 자동 팝업이 진행 중인 전투를 가리지 않음.
- 우편: 만료·취소·수령 완료 우편을 제외한 실제 수령 가능 우편만 점 표시.
- 패스: 무료 보상만 있어도 점 표시; 유료 미구매/XP 부족만 있으면 점 없음; 유료 구매 후 소급 수령이 가능하면 점 표시.
- 계정 전환·통신 실패: 이전 계정의 우편/패스 알림이 새 계정에 남지 않음. 실패를 빈 우편함이나 수령 완료로 오인하지 않음.
- 전화기 좁은 화면: 메인 재화·타워 숫자·탭 이름이 잘리지 않고, 출석 창을 닫거나 보상을 수령할 수 있음.

v118 완료 확인: 메인·출석·알림 브라우저 검사 56개와 알림 규칙 2개. 보상 UI 38개, 실제 게임 보상 통합 88개, 계정 클라이언트 17개, 구매 확인 휴대폰/PC, 순수운빨 고정 main 대조, 계정 전투 회귀 10개, 정적 앱 빌드도 통과했다. 실제 운영 계정의 발송이나 청구를 수행한 검증은 아니다.
