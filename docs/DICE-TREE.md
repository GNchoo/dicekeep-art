# 다이스 트리 · 각성 · 서포터 (v112)

2026-09-14. 새 덱빌드·극한 싱글·극한 멀티에 적용한다. 종류를 선택해 연구하는 성장으로 바꾸고, 전투의 7눈금에 고유 각성 능력과 선택형 서포터를 추가했다. 순수운빨·캠페인은 기존 전투 규칙을 유지한다. v111 이전에 시작한 전투도 당시 스냅샷으로 이어진다.

## 참조와 적용 범위

[Apple의 Random Dice 2 소개](https://apps.apple.com/kr/iphone/story/id6793009149?l=en-GB)는 자연·마법·공학·질서·혼돈 계열, 원하는 주사위 해금과 능력 연구를 선택하는 다이스 트리, 종류와 눈금의 구분을 설명한다. [개발사 Google Play 소개](https://play.google.com/store/apps/details?id=com.percent.aos.randomdice2&hl=ko)는 획득 가챠 없는 성장, 7성 각성, 선택형 서포터를 안내한다. 이를 기준으로 Dicekeep의 기존 20종과 아트에 맞게 구현했다.

연구 비용·보상·능력 수치와 5종 덱·3개 프리셋은 Dicekeep의 설정이다. 원작 최신 수치, 모든 기능 또는 합성 결과의 세부 확률을 그대로 복제한 것으로 주장하지 않는다. 기존 전투 소환·합성의 무작위성은 유지하고 **계정 해금과 연구 결과는 확정**한다.

## 종류와 눈금

편성 화면은 숫자 주사위 대신 종류별 타워 그림·이름·역할을 표시한다. 덱의 다섯 칸은 편성 자리이며 눈금 지정이 아니다. 다섯 종류가 각각 20% 확률로 1눈금 소환되고, 어느 종류든 전투에서 7눈금까지 성장한다. 같은 종류·눈금의 합성, 모사의 복제, 새싹의 시간 성장, SP로 올리는 종류별 파워업은 v111의 규칙을 잇는다.

| 계열 | 해금 순서 |
|---|---|
| 자연 | 서리 → 맹독 → 빙쇄 → 새싹 |
| 마법 | 비전 → 증폭 → 모사 → 맥동 |
| 공학 | 속사 → 포격 → 뇌전 → 균열 |
| 질서 | 축재 → 박동 → 추적 → 공명 |
| 혼돈 | 환원 → 소집 → 고독 → 군집 |

새 계정은 기존 여섯 종류(속사·포격·비전·서리·뇌전·축재)를 보유한다. 선행 종류를 해금하면 다음 종류를 연구할 수 있다. 이전에 가진 종류는 선행 해금 여부와 관계없이 보존한다.

## 연구와 비용

연구 골드는 전투로 얻고, 성장 조각은 무료 보상과 기존 확정 수량 상품의 동일한 자원이다. 연구에 성공 확률·실패·초기화 비용은 없다.

| 연구 | 연구 골드 | 성장 조각 | 조건 |
|---|---:|---:|---|
| 계열 첫째 / 둘째 종류 해금 | 120 | 0 | 둘째는 선행 종류 보유 |
| 셋째 종류 해금 | 240 | 10 | 선행 종류 보유 |
| 넷째 종류 해금 | 360 | 20 | 선행 종류 보유 |
| 숙련 0 → 1 | 100 | 0 | 종류 보유 |
| 숙련 1 → 2 | 160 | 5 | — |
| 숙련 2 → 3 | 240 | 10 | — |
| 숙련 3 → 4 | 340 | 15 | — |
| 숙련 4 → 5 | 460 | 20 | 최대 숙련 5 |
| 각성 해금 | 300 | 15 | 숙련 3 이상 |
| 특성 선택·변경 | 0 | 0 | 숙련 2 이상 |
| 서포터 선택·변경 | 0 | 0 | 시작부터 세 종류 모두 선택 가능 |

숙련은 단계당 기본 피해 +3%, 최대 +15%다. 새 트리 전투는 이전 클래스의 피해·수집 치명타 보너스를 중첩하지 않는다. 치명타 확률 10%, 피해 150%로 고정한다. 특성은 종류마다 **집중**(직접 공격·중독 피해 +10%) 또는 **통찰** 중 하나를 고른다. 통찰은 축재·새싹의 능력 주기를 10% 단축하고, 박동·증폭·공명의 인접 지원을 10% 높이며, 나머지 종류는 공격속도 +10%다.

새 계정은 연구 골드 1,860으로 시작한다. 기본 종류 하나를 숙련 3과 각성까지 연구하는 누적 비용은 800골드·30조각이다. 25웨이브 첫 정산은 1,120골드·45조각이며, 첫 101웨이브 완주는 5,308골드·170조각이다. 기본 여섯 종류 외의 전체 해금에는 총 3,360골드·140조각이 든다. 한 종류의 최대 숙련과 각성은 1,600골드·65조각이다. 자원 충족과 전투 중 7눈금 도달은 별개다.

## 20종 각성

해금한 각성은 해당 종류가 **7눈금**일 때만 발동한다. 6눈금 이하에는 적용하지 않는다. 타워는 기존 몸체 그림을 사용하고 각성 표시·능력 설명만 추가한다.

| 종류 | 각성 | 효과 |
|---|---|---|
| 속사 | 과속 | 공격속도 추가 +35% |
| 포격 | 거포 | 폭발 반경 66 → 105 |
| 비전 | 관통광 | 방어 무시 |
| 서리 | 영구빙 | 둔화 +15%p, 지속 3초 |
| 뇌전 | 뇌우 | 연쇄 대상 +3 |
| 축재 | 황금샘 | 생산 주기 8초, 생산량 +50% |
| 박동 | 심장박동 | 인접 공격속도 지원 효과 +50% |
| 증폭 | 과충전 | 인접 피해 지원 효과 +50% |
| 맹독 | 맹독안개 | 중독 피해 2배, 지속 5초 |
| 추적 | 거인사냥 | 보스 추가 피해 80% → 150% |
| 균열 | 붕괴 | 5초간 방어 80% 감소 |
| 빙쇄 | 빙하분쇄 | 둔화 대상 추가 피해 65% → 130% |
| 모사 | 완전모사 | 7눈금 복제 결과에 공격속도 +25%; 재변환 시 소멸 |
| 새싹 | 세계수 | 7눈금 유지, 전투 중 12초마다 70 SP |
| 소집 | 집결지 | 전투 중 20초마다 빈자리에 1눈금 추가 소환; 가득 차면 대기 |
| 환원 | 순환로 | 전투 중 15초마다 90 SP |
| 공명 | 대공명 | 이웃 눈금 조건 없이 피해 +50% |
| 고독 | 독무대 | 이웃이 없으면 추가 피해 120%, 사거리 +50 |
| 군집 | 대군집 | 같은 종류 개수 조건 3·5·7 → 2·4·6 |
| 맥동 | 진동파 | 강화 폭발 주기 4회 → 3회 |

## 전투 서포터

로비에서 하나를 선택하고 전투 버튼으로 직접 사용한다. 재사용 시간은 일시정지·웨이브 대기 중에는 감소하지 않는다. 타워가 필요한 분쇄, 적이 필요한 포격은 조건 불충족 시 비용과 재사용 시간을 소모하지 않는다.

| 서포터 | 효과 | 재사용 |
|---|---|---:|
| 보급관 | 80 + 필드 전체 눈금 합계(추가분 최대 40) SP | 45초 |
| 분쇄관 | 선택한 타워를 덱의 무작위 1눈금으로 교체, 기존 눈금 × 40 SP | 45초 |
| 포격관 | 선두 최대 8명에게 80 + 전체 눈금 × 18 피해, 보스에는 25% 적용 | 35초 |

서포터는 무료이며 별도의 레벨·뽑기·유료 해금이 없다. 현재 서포터 선택은 계정 공통이고, 세 덱 프리셋은 종류 편성을 저장한다. 전투가 시작되면 해당 런의 선택은 고정된다.

## 이전 투자와 저장 호환

`profile.tree.version=1`을 새로 만든 한 번만 환산한다. 소유권·예전 레벨·클래스 기록·덱·전투 기록·조각·무료/유료 지갑·영수증·환불 부채를 보존한다. 남은 중복 카드는 일반 25 / 희귀 50 / 영웅 100 / 전설 200골드, 남은 보급은 개당 420골드로 환산한다. 이전 클래스에 쓴 골드와 중복 카드 가치도 같은 종류의 숙련에 먼저 반영하고 남은 금액은 연구 골드가 된다. 이때 숙련 비용의 조각 가치는 개당 10골드로 계산한다.

표시 골드 상한을 넘는 환산액은 `tree.reserveGold`에 보존하고 연구 비용을 낼 때 자동 보충한다. 보급·중복 수량은 환산 후 0이 된다. 기존 미진행 무료 보급 지급분은 새 계정에도 같은 420골드 가치로 제공한다. 트리 계정은 예전 제작·보급·클래스·레벨 API를 호출해도 재화를 소모하지 않고 `tree-system`으로 거절한다.

새 스냅샷은 `deckSystem:1`에 `treeVersion:1`, 숙련·특성·각성 맵과 서포터를 추가한다. 시작 시 고정하고 재접속에도 같은 값을 사용한다. `supporterCooldown`, `supporterUses`, 복제 버프와 능력 타이머를 저장한다. 스냅샷에 트리 버전이 없는 v111 런은 당시 클래스 전투로 이어간다. 순수운빨은 기존 순수 스냅샷을 사용한다.

계정 보상은 기존 조각 계산을 유지한다. 완료 웨이브를 w라 할 때 새 연구 골드는 `8×min(w,500) + 40×새 마일스톤 수 + 5×기존 클리어 보너스 + 420×floor(min(w,200)/10)`이며 새 보급은 없다. 정산은 런 ID당 한 번이다. 서버 원장의 무료 조각 우선 차감과 환불 처리는 유지한다.

온라인 방은 같은 클라이언트 버전끼리 입장한다. v111 온라인 방의 경기 도중 v112로 새로고침하면 기존 버전 검사로 재입장이 거절될 수 있으므로 업데이트는 경기 종료 후 적용한다. 이는 오프라인 이전 저장 복구와 구분한다. 관전 패킷은 기존 종류·눈금 정보를 유지하며 상대의 각성 연구 정보는 전송하지 않아 상대 각성 배지를 표시하지 않는다.

## 검증

로컬 서버 주소는 `E2E_BASE_URL=http://127.0.0.1:8137/`로 지정할 수 있다.

- `npm run test:progression` / `test:commerce`: 확정 연구·조건·환산 보존·중복 정산·서버 원장
- `npm run test:tree-combat-rules` / `test:tree-combat`: 20종 각성·특성·서포터 전투와 조건
- `npm run test:tree-collection`: 실제 편성·해금·연구·특성 변경·서포터·휴대폰 레이아웃
- `npm run test:tree-resume` / `test:run-resume`: 새 트리와 이전 두 세대 런의 저장·복구·회전
- `npm run test:pure-main`: 순수운빨 원본 전체 규칙과 최대 트리 성장 계정의 전투 동등성
- `npm run test:game-modes` / `test:deck-combat`: 모드 경계·정산·v111 전투 호환
- `npm run measure:deck`: 무료 덱의 실제 전투 표본; 테스트용 준비 상태와 획득 보상을 구분해 기록

검사 결과는 [개발 현황](DEVELOPMENT-STATUS.md), 상품과 무료 성장 방침은 [비즈니스 모델](BUSINESS-MODEL.md)에 기록한다.
