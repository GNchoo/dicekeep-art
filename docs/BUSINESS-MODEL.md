# 외형 + 소액 성장 조각

2026-09-13 개발 기준. 사용자가 선택한 방향은 외형과 무료 플레이에서 받는 동일한 성장 조각의 판매다. 상품은 확정 지급·일회성 결제이며 구독, 입장권, 유료 전용 타워, 유료 부활은 없다. 순수운빨의 소환·피해·경제에는 구매 효과가 없다. 덱빌드와 극한에는 무료·구매 조각으로 올린 같은 계정 레벨이 적용되므로 성장 차이가 전투 차이로 이어진다.

| 상품 | 지급 | 웹 가격 초안 |
|---|---:|---:|
| 작은 성장 조각 | 200개 | 1,100원 |
| 성장 조각 | 600개 | 3,300원 |
| 넉넉한 성장 조각 | 2,000개 | 9,900원 |
| 왕실 / 서리 / 잿불 외형 | 각 주사위 재질 + 타워 20종 | 각 2,900원 |

작은 상품과 중간 상품의 개당 가격은 같다. 가장 큰 상품의 개당 할인은 10%로 제한했다. 기간 압박, 가짜 할인, 구매 팝업 자동 노출 없이 상점에서 선택한 경우에만 확인 창이 뜬다. 확인 창은 지급량·가격·일회성 결제를 보여주며 취소와 진행 버튼을 같은 크기로 배치하고 취소에 초기 초점을 둔다. 취소·Escape는 주문을 생성하지 않는다.

Android는 등록된 Google Play 상품의 실제 가격을 보여준다. 위 가격은 판매자 계정이나 상품 등록을 완료했다는 뜻이 아니다. 결제 서버 주소와 운영 계약·키·상품 등록이 없어 현재 실결제는 비활성 상태다. 실제 청구·취소 검증은 운영 설정을 받은 뒤 별도로 수행해야 한다.

## 무료 성장

모든 투기장 모드에 무료 성장 보상이 있고 입장료·횟수 제한은 없다. 25웨이브 최초 보상 45개로 기본 카드 업그레이드를 시작할 수 있다. 7성 해금 80개, 20성 해금 600개. 한 카드 Lv1→20은 1,045개, Lv1→200은 기존 353,545개에서 27,955개로 낮췄다. 5종의 Lv1→200 비용은 139,775개다. 최대 레벨은 장기 목표이며 모든 콘텐츠의 입장 조건이 아니다.

기존 Lv20 이후 투자 차액은 무료 조각으로 한 번 반환한다. 계정 레벨과 덱을 유지하며 반환 때문에 동일 성장 비용을 다시 결제할 필요가 없다. 서버 원장은 무료/유료 잔액을 구분하고 기존 환불 부채의 정상 상환 규칙을 유지한다.

600개는 101웨이브 재클리어 보상 120개의 5회분이다. 이는 자원량 비교이며 실제 플레이 시간이나 클리어 보장이 아니다. 투기장 자동 전투 측정은 덱별 2회이므로 이용자 승률·결제 전환율·적정 성장 기간은 아직 확정하지 않았다. 실제 이용자 자료 없이 결제 필요성을 높이는 방향으로 난이도를 조정하지 않는다.

## 검증과 다음 조정

구매 확인 UI의 취소/진행, 서버 금액 검증, 중복 지급 방지, 반환의 동시 요청·재로그인, 영수증 복구·환불 회귀를 로컬 가짜 공급자 응답으로 검증한다. 운영 결제는 호출하지 않는다. 기존 60개 SKU는 과거 영수증 호환만 유지한다.

다음 판단 지표는 신규 유저의 첫 해금까지 플레이 시간, 무료 덱의 성장별 도달 웨이브, 극한 재도전 시간, 조각 획득/사용 비율이다. 높은 레벨의 비용·보상은 이 자료를 보고 추가 조정한다.
