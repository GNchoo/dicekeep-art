# 외형 + 소액 성장 조각

2026-09-14, v112 기준. 사용자가 선택한 방향은 외형과 무료 플레이에서 받는 동일한 성장 조각의 판매다. 상품은 확정 지급·일회성 결제이며 구독, 입장권, 유료 전용 타워, 유료 부활은 없다. 순수운빨의 소환·피해·경제에는 구매 효과가 없다. 덱빌드와 극한은 다이스 트리의 숙련·특성·각성을 적용한다. 구매 조각은 연구를 앞당길 수 있지만 연구 골드도 함께 필요하며 골드는 플레이로 얻는다. 경쟁 성장 모드의 유료 성장 속도 차이를 완전히 없앤 구조는 아니다.

| 상품 | 지급 | 웹 가격 초안 |
|---|---:|---:|
| 작은 성장 조각 | 200개 | 1,100원 |
| 성장 조각 | 600개 | 3,300원 |
| 넉넉한 성장 조각 | 2,000개 | 9,900원 |
| 왕실 / 서리 / 잿불 외형 | 각 주사위 재질 + 타워 20종 | 각 2,900원 |

작은 상품과 중간 상품의 개당 가격은 같다. 가장 큰 상품의 개당 할인은 10%로 제한했다. 기간 압박, 가짜 할인, 구매 팝업 자동 노출 없이 상점에서 선택한 경우에만 확인 창이 뜬다. 확인 창은 지급량·가격·일회성 결제를 보여주며 취소와 진행 버튼을 같은 크기로 배치하고 취소에 초기 초점을 둔다. 취소·Escape는 주문을 생성하지 않는다.

Android는 등록된 Google Play 상품의 실제 가격을 보여준다. 위 가격은 판매자 계정이나 상품 등록을 완료했다는 뜻이 아니다. 결제 서버 주소와 운영 계약·키·상품 등록이 없어 현재 실결제는 비활성 상태다. 실제 청구·취소 검증은 운영 설정을 받은 뒤 별도로 수행해야 한다.

## 무료 성장

모든 투기장 모드에 무료 성장 보상이 있고 입장료·횟수 제한은 없다. 새 계정에는 기본 주사위 6종과 연구 골드 1,860을 지급한다. 자연·마법·공학·질서·혼돈 계열에서 원하는 종류를 순서대로 확정 해금한다. 새 성장에서는 무작위 카드 보급과 중복 카드 제작을 사용하지 않는다.

첫째·둘째 종류는 120골드만으로, 셋째는 240골드·10조각, 넷째는 360골드·20조각으로 해금한다. 기본 여섯 종류 외의 전체 해금 비용은 3,360골드·140조각이다. 숙련은 최대 5단계로 피해가 총 15% 증가하며, 숙련 2부터 무료로 두 특성 중 하나를 선택·변경한다. 각성은 숙련 3에서 연구하고 실제 전투에서 7눈금에 도달해야 발동한다. 세 서포터는 시작부터 모두 무료 선택할 수 있다.

기본 주사위 하나의 숙련 3과 각성까지는 총 800골드·30조각이다. 25웨이브 최초 보상 1,120골드·45조각으로 충당할 수 있다. 첫 101웨이브 완주는 5,308골드·170조각을 지급한다. 한 종류의 최대 숙련과 각성은 총 1,600골드·65조각이다. 조합을 바꿀 때 특성을 다시 구매하거나 서포터를 해금할 필요가 없다.

이전 해금·레벨·덱·잔액은 보존하고, 기존 클래스 투자·중복·미개봉 보급을 숙련과 연구 골드로 한 번 환산한다. 상한을 넘는 환산 골드도 예비 잔액으로 보존한다. 자세한 식과 저장 호환 규칙은 [다이스 트리](DICE-TREE.md)에 있다. 서버 원장은 무료/유료 조각을 구분하고 무료 잔액을 먼저 사용하며 기존 환불 부채의 상환 규칙을 유지한다.

600조각은 101웨이브 재클리어 조각 보상 120개의 5회분이다. 이는 자원량 비교이며 실제 플레이 시간이나 클리어 보장이 아니다. 무료 기본 덱을 기준으로 전투 표본을 측정하고, 숙련이나 각성을 구매해야만 기본 완주가 가능하도록 적 수치를 올리지 않는다. 측정 결과는 [개발 현황](DEVELOPMENT-STATUS.md)에 기록한다. 이용자 승률·결제 전환율·적정 성장 기간은 아직 확정하지 않았으며 실제 이용자 자료 없이 결제 필요성을 높이는 방향으로 난이도를 조정하지 않는다.

## 검증과 다음 조정

구매 확인 UI의 취소/진행, 서버 금액 검증, 중복 지급 방지, 반환의 동시 요청·재로그인, 영수증 복구·환불 회귀를 로컬 가짜 공급자 응답으로 검증한다. 운영 결제는 호출하지 않는다. 기존 60개 SKU는 과거 영수증 호환만 유지한다.

다음 판단 지표는 첫 원하는 종류·특성·각성 연구까지의 시간, 무료 덱의 숙련별 도달 웨이브, 조합·서포터 사용률, 연구 골드·조각 부족 비율, 극한 재도전 시간이다. 각성 해금률과 실제 7눈금 도달률도 구분해 측정한다. 능력과 성장 비용·보상은 이 자료를 보고 추가 조정한다.
