# 외형 + 소액 성장 조각

2026-09-14, v111 기준. 사용자가 선택한 방향은 외형과 무료 플레이에서 받는 동일한 성장 조각의 판매다. 상품은 확정 지급·일회성 결제이며 구독, 입장권, 유료 전용 타워, 유료 부활은 없다. 순수운빨의 소환·피해·경제에는 구매 효과가 없다. 덱빌드와 극한에는 수집 클래스가 적용된다. 구매 조각으로 중복 카드를 확보할 수 있으므로 성장 속도 차이는 있지만 클래스 강화에 필요한 수집 골드는 플레이로 얻는다.

| 상품 | 지급 | 웹 가격 초안 |
|---|---:|---:|
| 작은 성장 조각 | 200개 | 1,100원 |
| 성장 조각 | 600개 | 3,300원 |
| 넉넉한 성장 조각 | 2,000개 | 9,900원 |
| 왕실 / 서리 / 잿불 외형 | 각 주사위 재질 + 타워 20종 | 각 2,900원 |

작은 상품과 중간 상품의 개당 가격은 같다. 가장 큰 상품의 개당 할인은 10%로 제한했다. 기간 압박, 가짜 할인, 구매 팝업 자동 노출 없이 상점에서 선택한 경우에만 확인 창이 뜬다. 확인 창은 지급량·가격·일회성 결제를 보여주며 취소와 진행 버튼을 같은 크기로 배치하고 취소에 초기 초점을 둔다. 취소·Escape는 주문을 생성하지 않는다.

Android는 등록된 Google Play 상품의 실제 가격을 보여준다. 위 가격은 판매자 계정이나 상품 등록을 완료했다는 뜻이 아니다. 결제 서버 주소와 운영 계약·키·상품 등록이 없어 현재 실결제는 비활성 상태다. 실제 청구·취소 검증은 운영 설정을 받은 뒤 별도로 수행해야 한다.

## 무료 성장

모든 투기장 모드에 무료 성장 보상이 있고 입장료·횟수 제한은 없다. 새 계정에는 기본 카드 6종, 수집 골드 600, 무료 보급 3개를 지급한다. 보급은 카드 5장과 골드 120을 지급하며 현금이나 조각으로 판매하지 않는다. 카드 희귀도 확률과 전설 20회 보장은 개봉 버튼 근처에 공개한다. 보유 보급은 만료되지 않는다.

원하는 카드의 확정 제작은 희귀도에 관계없이 20조각이다. 일반/희귀/영웅/전설은 각각 8/4/2/1장이다. 처음 한 장은 해금, 이후는 클래스 강화 재료가 된다. 25웨이브 최초 보상 45조각이면 원하는 종류를 두 번 제작할 수 있다. 같은 전투에서 보급 2개와 수집 골드 280도 얻는다. 클래스는 카드와 골드를 함께 사용해 최대 20까지 올린다. 기본 클래스의 무료 조합도 101웨이브를 클리어할 수 있도록 전투를 구성했다.

이전 해금·레벨·덱·잔액은 보존하고, 기존 강화 투자는 새 클래스·중복 카드·수집 골드로 한 번 환산한다. 자세한 식과 저장 호환 규칙은 [덱 시스템](DECK-SYSTEM.md)에 있다. 서버 원장은 무료/유료 조각을 구분하고 무료 잔액을 먼저 사용하며 기존 환불 부채의 상환 규칙을 유지한다.

600조각은 101웨이브 재클리어 보상 120개의 5회분, 또는 카드 확정 제작 30회분이다. 이는 자원량 비교이며 실제 플레이 시간이나 클리어 보장이 아니다. 새 전투의 초기 측정은 서로 다른 6개 조합 각 한 번으로, 신규 기본 덱을 포함한 시작 클래스의 4개 조합이 완주했다. 이용자 승률·결제 전환율·적정 성장 기간은 아직 확정하지 않았다. 실제 이용자 자료 없이 결제 필요성을 높이는 방향으로 난이도를 조정하지 않는다.

## 검증과 다음 조정

구매 확인 UI의 취소/진행, 서버 금액 검증, 중복 지급 방지, 반환의 동시 요청·재로그인, 영수증 복구·환불 회귀를 로컬 가짜 공급자 응답으로 검증한다. 운영 결제는 호출하지 않는다. 기존 60개 SKU는 과거 영수증 호환만 유지한다.

다음 판단 지표는 첫 원하는 카드 획득 시간, 무료 덱의 클래스별 도달 웨이브, 조합별 사용률, 골드·중복 카드 부족 비율, 극한 재도전 시간이다. 카드 능력과 성장 비용·보상은 이 자료를 보고 추가 조정한다.
