# Random Dice 2 모드 조사와 Dicekeep 적용 경계

조사일: 2026-09-14. 대상은 111%의 **Random Dice 2**, Android 패키지 `com.percent.aos.randomdice2`, iOS 앱 `6748432502`다. 전작 Random Dice: Defense, Wars, Go, RollRoll, 운빨존많겜의 규칙을 섞지 않았다.

## 결론

RD2의 협동 화면에 나오는 **5,000은 5,000라운드가 아니라 두 플레이어의 누적 몬스터 처치 수**다. 일반 난이도에서는 이 수치로 끝난 결과 화면을 직접 확인했다. 서로 주사위 판을 운영하면서 같은 적의 진군을 막고, 결과에 공동 처치 수와 두 사람의 기여도를 표시한다. 아레나는 이와 별도로 상대에게 몬스터를 보내며 생존을 겨루는 1 대 1 경쟁이다.

최신 공식 버전 기록상 2026-09-05에 **어려움 난이도**가 추가됐다. 따라서 8월 작성 공략의 ‘하드가 아직 없다’는 설명은 현재 기준으로 사용할 수 없다. 공식 스토어 설명에는 모드별 모든 숫자와 승패 세칙이 공개되어 있지 않다. 아래의 ‘실제 화면 관찰’과 ‘비공식 설명’을 공식 규칙표로 바꾸어 인용하지 않는다.

## 실제 게임 화면 관찰

### 일반 협동

[2026-09-06의 사용자 플레이 이미지 두 장](https://gall.dcinside.com/mgallery/board/view/?id=randomdice2&no=21928)을 브라우저로 열어 직접 확인했다. 게시글 주장과 화면에서 읽을 수 있는 사실을 구분한다.

- 첫 이미지: 상단에 **5000 / 처치한 몬스터 / 일반**, 두 플레이어 프로필, 기여도 막대가 보인다. 위아래에 각각 5 × 3 주사위 판이 있으며 가운데 길과 성채가 있다. 해당 판의 성채 HP는 110이다. 이를 모든 계정의 초기 HP라고 단정하지 않는다.
- 둘째 이미지: **게임 종료 / 일반 / 5000 / 처치한 몬스터**, 두 플레이어 기여도 66% / 34%가 보인다.
- 이 관찰로 일반의 5,000 처치 종료 사례와 두 사람이 공동 기록을 만든다는 점을 확인했다. 이미지 한 쌍만으로 패치별 누수 계산·추가 소환 몬스터의 집계 세칙까지 확정하지 않는다.

### 어려움 협동

[파워나갔다의 어려움 플레이 영상](https://www.youtube.com/watch?v=LffR7akNzVI&t=655s)을 직접 열어 8,000 부근까지 진행하는 어려움 전투를 확인했다. 따라서 ‘모든 난이도가 5,000에서 종료된다’고 일반화할 수 없다. [어려움 첫 클리어 영상](https://www.youtube.com/watch?v=r2gJSGefWlA)도 확인 대상으로 확보했다.

## Dicekeep 적용 제안

협동의 공동 목표와 경쟁의 상대 생존 경쟁을 별도 규칙으로 만든다. 기존 101웨이브 싱글 클리어와 현재 극한 멀티의 규칙을 바꾸지 않고 새 모드를 추가하는 편이 기존 기록과 저장을 보존한다.

1. **협동:** 공동 HP, 공동 몬스터 처치 목표, 동료에게 직접 도움이 되는 무료 지원 능력을 둔다. 공동 성공/패배를 같은 시점에 판정하고 개인 기여도만 보조 정보로 표시한다. 낮은 화력 역할도 보상이 줄지 않도록 한다.
2. **1 대 1:** 처치로 상대에게 압박을 보내고 먼저 HP 0이 된 쪽이 패배한다. 싱글 최종 웨이브 동시 클리어를 PvP 승리 조건으로 재사용하지 않는다. 통신 중복·지연에도 같은 처치 전송이 두 번 적용되지 않아야 한다.
3. **숫자 표기:** RD2의 5,000을 Dicekeep의 5,000웨이브로 옮기지 않는다. 목표 처치 수, HP, 보스 간격, 지원량은 Dicekeep 전투 속도에 맞춘 자체 설정이라고 문서화한다.
4. **구매 부담:** 입장권 과금, 유료 이어하기, 구매 전용 협동 지원은 도입하지 않는다. 확정 무료 보상을 유지하고 유료 자원은 이미 무료로 얻는 성장 자원의 범위에 한정한다.
5. **검증:** 기존 솔로 덱 순위는 동일 연구 단계·서포터·시드·조작 정책으로 측정한다. 협동 덱은 동료 조합과 역할에 의존하므로 솔로 순위를 그대로 협동의 절대 순위로 표시하지 않는다.
