# 전투 모션 상태 (v108)

2026-09-14. v107의 상체 변형은 사용자 검토에서 울렁이는 필터처럼 보인다는 평가를 받았다. 구간별로 이미지를 휘는 방식은 관절 애니메이션을 대신할 수 없었고, 자연스러운 동작을 완성했다는 이전 판단은 잘못이었다.

## 상체 변형 철회

- 8구간 이미지 변형과 골반·가슴·머리의 사인파 오프셋을 완전히 제거했다. 강도만 낮추거나 다른 흔들림으로 바꾸지 않았다.
- 몬스터와 보스는 기존 방향별 보행·날갯짓 프레임을 원래 형태 그대로 그린다. 피격 흰 실루엣과 진화 장식에도 상체 변형을 적용하지 않는다.
- 명중 표시점에서도 해당 오프셋을 제거했다. 공중 적의 표시 높이 보정과 W100 파멸의 군주의 지상 보행 수정은 유지한다.
- 비교 HTML에서 몬스터의 원본/현재는 같은 프레임이다. 상체를 자연스럽게 새로 제작한 상태로 표시하지 않는다.

상체 모션은 기존 수준으로 복원했다. 자연스러운 새 상체 애니메이션은 아직 완성하지 않았다. 다시 제작할 때는 캐릭터별로 머리·몸통·팔·무기를 분리하고 관절과 접지를 맞춘 소수 표본을 먼저 검토해야 한다.

## 유지한 변경

타워 20종의 포구/마력 장치 반동·충전·복귀, 투사체·명중 효과 11계열은 유지한다. 건물 받침은 고정한다. 이미지 캐시의 현재 방향 시트 우선순위와 불필요한 해제/재로딩 방지 수정도 유지한다. 96MiB와 동시 로드 2개 제한, 같은 캐릭터/방향의 대체 이미지는 그대로다.

유료 생성 서비스나 MCP를 사용하지 않았다. 전투 피해·공격 주기·판정·성장/과금 수치를 변경하지 않는다.

## 검증

`npm run test:combat-motion`은 W100 지상/비행 보스와 W1 일반 몬스터의 앞·뒤·옆 실제 시트 모든 프레임을 원본 직접 그리기와 픽셀 대조한다. 프레임 사이에 기존 동작이 계속 달라지는지도 확인한다. 같은 명령에서 v106 `2fb8489`와 60개 공격의 피해·명중 틱·상태 이상·좌표·난수를 대조하고, 타워 장치/받침과 200마리·15타워 그리기를 검사한다.

`npm run test:boss-locomotion`은 318스폰과 저장/관전의 보스 이동 규칙을 검증한다. `npm run build:www`는 배포 파일에 v108 모듈을 포함한다. 실행 결과는 `gen/e2e`에 저장한다. 이번 픽셀 검사는 왜곡 제거의 증거이며 새로운 모션의 미적 완성도를 뜻하지 않는다.

v108에서 위 세 명령을 재실행해 통과했다. 60개 원본 프레임의 픽셀이 모두 동일했고 기존 팔다리 프레임 변화가 유지됐다. 60개 공격 결과도 기준과 동일했다. 두 화면의 200마리·15타워 그리기 오류는 0이었으며 배포 파일 2,243개를 생성했다.

v107에서 통과한 순수운빨 84검사, 저장 복구, 스킨 각 화면 90검사, 캐시 26검사 및 111종·200마리 압력 검사 기록은 이전 커밋 문서에 남아 있다. 이번에 수정하지 않은 영역의 검사를 전부 재실행하지는 않는다. 실제 휴대폰 하드웨어의 발열과 성능 검사는 수행하지 않았다.

## 확인 화면

`npm run test:combat-motion`은 `gen/e2e/combat-motion/preview.html`을 생성한다. 원본/현재 좌우 비교, 앞·뒤·옆 방향, 일시정지와 절반 속도를 지원하며 실제 이미지를 내장해 오프라인으로 재생된다. 몬스터의 크기는 비교용으로 통일했다.
