# 전투 모션 상태 (v110)

2026-09-14. 사용자 검토에 따라 몬스터 상체 변형과 타워 장치 변형을 철회했다. 현재는 원본 몬스터 프레임과 기존 타워 공격 표현을 사용하며 타워 발사 순간의 빛만 추가한다.

v110은 인간형 103종의 무릎 방향을 수정한 아트 재생성이다. 최종 빌드·검수·승격·런타임 확인을 완료했다. 아래 v109 검증 기록과 v110에서 새로 확인한 범위를 구분한다.

## 현재 적용 상태

- 몬스터/보스의 원본 보행·날갯짓 프레임을 변형 없이 그린다. v107의 상체 울렁임은 v108에서 제거했다.
- 타워 몸체, 전체 압축과 발광, 기존 투사체·꼬리·빔·명중 효과를 v106 main `2fb8489`의 코드로 복원했다.
- 포구 섬광과 마법빛만 발사 직후 0.14~0.18초 표시한다. 타워 그림을 잘라 옮기거나 코어를 움직이지 않는다. 지속 충전 효과도 없다.
- 빛은 실제 발사 성공 시 시작하며 냉각/대기 중에는 나오지 않는다. 기존 압축 비율에 맞춰 표시해 타워 포구를 따라간다.
- W100 보스의 지상 보행 수정, 방향별 아트 캐시 개선, 상체 필터 제거는 유지한다.
- 유료 생성 서비스나 MCP를 사용하지 않았다. 피해·확률·공격 주기·성장/과금 수치는 변경하지 않았다.

## v109 검증 기록

`npm run test:combat-motion`으로 아래를 확인했다.

- 60개 실제 공격의 피해·최초 명중 틱·주기·둔화/기절·물리 좌표·난수가 v106과 동일하다.
- 20타워·3스킨·4반동 상태의 몸체 픽셀이 기존 그리기 함수와 동일하다. 발사빛은 나타났다 사라진다.
- W100 지상/비행 보스와 W1 일반 몬스터의 3방향 60프레임은 원본 픽셀과 동일하다.
- 두 화면 크기의 200마리·15타워에서 페이지/아트 오류 0, 추적 캐시 96MiB 이내다.

실제 스킨 검사는 휴대폰/데스크톱 크기 각 90건 통과했다. `npm run build:www`는 새 모듈을 포함한 2,243파일을 생성한다. 실제 휴대폰 하드웨어의 발열/성능 검사는 수행하지 않았다.

## 인간형 무릎 수정 (v110)

b201은 b100의 기본 형태/리그를 재사용한 변형이라 실루엣이 거의 같다. 이 외형 재설계는 무릎 수정 범위에 포함하지 않는다.

닭 형태의 w075·w176은 의도된 hock 관절로 분류하고 유지했다. 수정 대상은 기존 51종과 극한 52종의 합계 103종이다. 98종은 세 방향 모두, 초기 다섯 인간형은 정면/후면만 고쳤다. 다섯 종의 정상 측면은 그대로 보존했다.

수정 방향의 다리를 기존 원화와 관절 정보로 시트로 다시 생성했다. 전체 304뷰의 보행 2,432프레임, 정지컷/보행 시트 608파일과 304개 fallback을 교체했다. 몸통을 휘게 하는 필터나 새 타워 동작은 넣지 않았다. 기존 발끝 반전·접지·보폭·피벗·기준 높이를 보존하고, 인간형 무릎이 뒤로 굽으면 빌드가 실패하는 해부 검사도 추가했다.

전체 관절·래스터·이동 검사와 최종 `npm run test:biped-knees`가 통과했다. 측면 프레임 2·6은 98종 전후를 검수하고 대표 여섯 종의 세 방향 8프레임, 초기 다섯 종의 정면/후면 80포즈도 확인했다. 모든 프레임의 시각 검수를 뜻하지 않는다. 최종 검사에는 단위/관절 26건, 실제 게임 103종×3방향×2화면(618배치), 서버 이미지 608개·fallback 304개 디코드가 포함된다. 비대상 118종과 초기 다섯 종의 측면 메타데이터·718이미지가 기준 main과 같았다. W100 지상 보스와 비행 부관을 유지하고 페이지/아트 오류는 0이었다. `npm run build:www`는 2,243파일로 완료했다.

최종 세 방향 감사는 인간형 전방 103종/309뷰·조류 hock 2종/6뷰이며 뒤쪽·혼합·미해결 인간형은 0이다. 원인은 `BIPED-KNEE-AUDIT.md`, 재현 명령과 실제 결과는 `tools/art-review/biped-knees-110/README.md`에 있다.

## 확인 화면

`npm run test:combat-motion`은 실제 게임 이미지를 내장한 `gen/e2e/combat-motion/preview.html`을 만든다. 타워의 왼쪽/오른쪽 몸체 모션은 같고 오른쪽에만 새 발사빛을 추가한다. 몬스터 양쪽도 같은 원본 프레임이다. 앞·뒤·옆 방향, 일시정지와 절반 속도를 지원하며 저장 후 오프라인으로 열 수 있다.
