# 자체 제작 전투 모션 (v107)

2026-09-14. 기존 이미지를 Canvas에서 부위별로 변형하고 공격 효과를 직접 그리는 방식으로 적용했다. 유료 생성 도구·MCP·새 라이브러리를 사용하지 않아 추가 서비스 비용은 없다. 새로 그린 전신 스프라이트 시트가 아니라, 기존 팔다리 프레임에 상체의 연속 움직임을 더한 런타임 애니메이션이다.

## 적용한 표현

- 몬스터·보스 221종: 보행은 발과 하단 정강이를 고정하며 골반과 가슴을 반대로 움직이고 머리는 작게 뒤따른다. 비행은 날갯짓에 가슴이 반응하고 머리·하단 부위가 시차를 가진다. 부유·기어가기에 별도 곡선을 적용했다. 앞·뒤·옆 방향 모두 기존 이동/둔화/정지 시계에 맞춘다.
- 타워 20종: 건물 전체 압축을 제거했다. 포구 안쪽의 후퇴와 복귀, 교대 포격, 마력 코어 움직임, 충전 빛과 룬, 전격 코일의 방전을 그린다. 받침은 고정하며 공격 시간은 화면 프레임 수 대신 게임 시간에 맞춘다.
- 투사체·명중: 레이저·포격·비전·서리·전격·주사위·별·성운·영웅·신화·태초 11계열로 구분했다. 포탄/얼음 조각/주사위/창/궤도 핵/칼날의 실루엣과 꼬리, 연기·압력파·얼음 파편·전격·룬 형태를 적용한다. 실제 포구에서 출발하고 공중 적 몸통에도 명중 효과가 보이도록 표시점을 보정했다.
- 관전도 같은 렌더러를 사용한다. 기존 레이저/번개 빔, 일부 발사 섬광과 진화 장식은 유지한다.

전투 좌표와 표시 좌표를 분리했다. 피해·명중 시점·공격 주기·범위·확률 수치는 변경하지 않았다. W100 파멸의 군주가 지상에서 걷는 수정은 v106에 포함되었고 이번에도 유지된다.

## 메모리와 많은 적의 처리

한 프레임을 8개 구간으로 연속 변형하며 매 프레임 새 이미지/캔버스를 만들지 않는다. 기존 캐시는 모든 방향의 고해상도 정지 이미지를 고정해 200마리 상황에서 애니메이션 시트를 불러오지 못했다. 현재 방향 시트를 우선하고 정지 이미지는 필요할 때 해제한다. 해제해도 시트를 넣을 수 없으면 유용한 정지 이미지를 불필요하게 지웠다 다시 읽지 않는다.

이미지 캐시와 디코딩 예약 합계는 기존 96MiB, 동시 로드는 2개다. 부족하면 같은 캐릭터·같은 방향의 정지/64px 대체 프레임에 상체 움직임을 적용한다. 200마리 모두가 동시에 원본 해상도 팔다리 시트를 재생한다는 의미는 아니다. 이 한도는 브라우저·GPU 전체 메모리가 아니다.

## 검증과 재현

정적 서버를 8137번 포트에서 실행한다.

```sh
npm run test:combat-motion
npm run test:boss-locomotion
npm run test:pure-main
npm run test:run-resume
node --test net/test/infinity-art.test.js
node tools/e2e/directional-review-regressions.cjs
node tools/e2e/directional-cache-pressure.cjs --extreme
# E2E_BASE_URL=http://localhost:8137/ 를 지정해 실행
node tools/e2e/cosmetics.cjs
npm run build:www
```

- 이전 main `2fb8489`의 60개 실제 공격과 피해·최초 명중 틱·주기·둔화/기절·투사체 좌표·난수가 동일했다.
- 221종·3시점 변형값, W100 발 고정/상체 픽셀 변화, 20타워 장치 변화/받침 고정을 검증했다. 받침 픽셀 비교는 GPU의 1단계 색상 반올림만 허용한다.
- 순수운빨 101웨이브 규칙 표, 이전 main의 12웨이브 전투 기준과 계정 무관성 84검사, 보스 318스폰, 이어하기 두 화면이 통과했다.
- 캐시 26검사와 비행/부유 속도 54사례, 보스 5주기 로스터, 실제 PNG 재로딩 복구가 통과했다. 외형 스킨 3테마는 휴대폰/데스크톱 크기 각 90검사가 통과했다.
- 실제 극한 111종을 공유하는 200마리의 4방향 압력 검사에서 모든 캐릭터/방향이 표시되고 실제 시트와 대체 프레임이 함께 사용됐다. 최대 96MiB, 오류 0, 적 제거 후 필수 캐시로 복귀했다.
- 200마리·15타워 그리기를 검사했다. 데스크톱 Chrome에서 휴대폰 크기의 CPU 제출 시간 p50/p95는 7.3/10.9ms, 데스크톱 크기는 10.2/13.7ms였다. 동시 실행 부하에 따라 변하는 표본이며 실제 휴대폰 FPS/발열 검사는 아니다.
- 배포용 빌드 2,243파일에 새 모듈을 포함했다.

`npm run test:combat-motion`은 실제 게임 프레임을 내장한 `gen/e2e/combat-motion/preview.html`도 만든다. 기존/개선 좌우 비교, 앞·뒤·옆 방향, 일시정지와 절반 속도를 지원하며 저장 후 오프라인으로 열 수 있다. 원자료는 Git에서 제외하는 `gen/e2e`에, 재현 코드는 저장소에 보관한다.

## 남은 품질 확인

관절마다 팔·무기를 다시 그린 애니메이션은 아니다. 캐릭터별 손·무기 연기와 큰 회전 동작은 원본 부위 분리와 개별 리그 보강이 필요하다. 이번 결과를 플레이에서 검토한 뒤 과장된 변형이나 부족한 동작을 종별로 조정할 수 있다. 실제 휴대폰의 장시간 발열과 터치/백그라운드 전환 확인은 남아 있다.
